# Pricing Page

## Goals
- Help the buyer self-select a plan fast
- Make the recommended plan obvious
- Answer billing objections without sales call

## Structure
1. Headline + billing period toggle (monthly/yearly)
2. 2–4 tiers max (most teams: Free/Pro/Business)
3. Feature comparison table (progressive disclosure on mobile)
4. FAQ (seats, taxes, refunds, limits)
5. Final CTA

## Tier cards
- Name, price, who it's for
- 4–7 bullets max on card; rest in table
- Highlight one recommended tier
- Primary CTA per card, same verb family

## Honesty
- No fake "most popular" without data intent
- Limits clear (not only in ToS)

## Acceptance
- User can answer "which plan for me?" in 30 seconds
