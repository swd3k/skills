# Landing Page

One page · one audience · one primary action.

## Gather first
- Primary CTA (trial / buy / waitlist / download)
- Offer, ICP, top objections
- Proof assets, risk reversal
- Traffic source

## Structure
**Above the fold:** headline, subhead, CTA, proof, hero visual  
**Middle:** problem→solution, benefits, how it works, social proof  
**Bottom:** FAQ, risk reversal, final CTA

## Layout picks
- Classic hero + sections (default)
- Long-form sales page (high skepticism)
- Minimal convert page (high intent)
- Comparison page (alternatives intent)

## Copy rules
- Outcome + audience in headline
- Specificity beats "streamline"
- CTA = verb + value
- One primary CTA above the fold

## Output
1. Outline
2. Hero copy
3. Benefits (3–5)
4. How it works (3)
5. FAQ (6–12)
6. SEO/AEO note
7. Layout recommendation

## Pitfalls
- Multiple competing CTAs
- Feature dump without outcomes
- Proof buried
