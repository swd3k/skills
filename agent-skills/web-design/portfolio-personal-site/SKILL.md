# Portfolio / Personal Site

## Goals
- Prove craft in 10 seconds
- Make contact or hire path obvious
- Load fast; images intentional

## Structure
- Hero: name, role, one-liner, CTA
- Selected work (3–6 cases, not 40 thumbnails)
- About (short)
- Contact

## Case study pattern
Problem → Role → Process → Outcome → Media

## Rules
- Quality over quantity
- Real metrics when available; no fake "300% conversion"
- Consistent project card grid
- Good favicon + OG image

## Acceptance
- Lighthouse-friendly images
- Mobile nav and contact work
