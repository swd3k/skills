# Polished Marketing Site

Memorable first viewport + disciplined system. Not gradient soup.

## Direction first (write before code)
- Visual thesis (one sentence)
- Type pair + scale
- Color tokens (bg, text, accent)
- Section sequence
- Motion: entrance + scroll (one system)
- Asset plan (original/licensed)

## Build order
1. Global tokens + type
2. Nav + hero (complete static frame)
3. Sections with shared spacing rhythm
4. Motion progressive enhancement
5. Footer + SEO meta
6. Performance pass

## Motion rules
- One primary library (e.g. CSS + light GSAP) — don't stack three
- Respect `prefers-reduced-motion`
- Hero usable before animation ends

## Reject
- Glass everywhere, ornamental bento with no content
- Stock fake testimonials
- Lorem in production
- "Award-winning" claims without proof

## Acceptance
- Lighthouse performance sensible on marketing content
- Mobile nav works
- Keyboard focus visible
