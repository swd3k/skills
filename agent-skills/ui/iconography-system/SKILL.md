# Iconography System

## Defaults
- One family only (e.g. Lucide, Heroicons, Fluent, Solar)
- Optical size 16/20/24; stroke width consistent
- Align to text cap height in buttons
- Prefer text + icon for primary destructive/critical actions

## Rules
- Same metaphor everywhere (trash = delete)
- Don't invent one-off stroked/filled mixes
- Provide aria-labels for icon-only

## Desktop
- Tray icons: simple silhouette, tested on light/dark taskbar
- App icon: recognizable at 16 and 256

## Acceptance
- No three different icon libraries in one screen
